# Vedanth Kambali — Portfolio

A responsive personal portfolio website built using plain HTML and CSS.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a repository (for example, `portfolio`).
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, and save.
6. Wait for GitHub Pages to publish your website.
